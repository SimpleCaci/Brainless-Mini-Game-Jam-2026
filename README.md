# Maple the Shepherd
### Brainless Mini-Game Jam 2026

A 2D Godot jam game about helping Maple bring sheep back to the barn, with retro golf-inspired movement.

**[Download the released game on itch.io](https://sim-ple.itch.io/maple-the-shepherd)** · [Jam page](https://itch.io/jam/brainless-mini-game-jam) · [Credits](CREDITS.md) · [Development notes](docs/DEVELOPMENT.md)

The itch.io page lists Windows and Linux downloads. This repository preserves the editable project and historical exports; a checked-in export is not necessarily identical to the current itch.io download.

## Creators

Made by **Pia and SimpleCaci**, as credited on the [official game page](https://sim-ple.itch.io/maple-the-shepherd). The page also directs readers to Pia’s art. See [CREDITS.md](CREDITS.md) for attribution and the existing license notice.

## Open the source

1. Start with Godot 4.5, the version declared in the project configuration.
2. Import `brainless-game-jam-2026/project.godot`.
3. Let Godot import the assets, then run the configured main scene.

Opening the source is separate from downloading the released builds. No game execution or new export was performed during this documentation update.

## Repository layout

- `brainless-game-jam-2026/scenes/` — menus, levels, characters, and UI scenes.
- `brainless-game-jam-2026/scripts/` — gameplay and interface scripts.
- `brainless-game-jam-2026/assets/` — pixel art and interface assets.
- `brainless-game-jam-2026/audio/` — audio resources.
- Root `index.*`, `game.zip`, and `winOS.zip` — historical exported artifacts.

## Project status

The game is listed as released on itch.io. The source configuration includes export presets, but preset presence alone does not establish a working build for every platform. For the available release downloads, use itch.io.

This documentation preserves the original jam project. Gameplay, assets, and historical builds were not replaced.
