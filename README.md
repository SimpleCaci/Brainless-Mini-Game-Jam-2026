# Brainless Mini Game Jam 2026

A compact Godot game created for the 2026 Brainless Mini Game Jam, featuring original game scenes, character art, sound, and exported builds.

## Tech stack

- Godot 4.5
- GDScript
- 2D pixel-art assets
- Web and Windows export targets

## Open the project

1. Install Godot 4.5 or a compatible Godot 4 release.
2. Import `brainless-game-jam-2026/project.godot`.
3. Open the project and run its configured main scene.

## Repository layout

- `brainless-game-jam-2026/` — editable Godot source.
- `assets/` inside the project — characters, UI, sounds, and backgrounds.
- Export folders — playable builds created for jam submission and sharing.

## Status

Completed game-jam project preserved as a creative development case study. Future presentation work should add gameplay screenshots and a short recording rather than changing the original jam scope.
